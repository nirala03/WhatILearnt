# Technical Writing Lab — Assignment Portfolio

This repository brings together a collection of practical exercises completed as part of the **Technical Writing Lab (TW Lab 2025)**. It explores the tools, methods, and conventions commonly used to prepare technical documents, communicate complex ideas, and maintain software-related information.

The work spans several areas of technical communication. These include mathematical typesetting, presentation development, automatic generation of software documentation, and the use of version control. Each area introduces a different way of handling technical information, from its initial preparation to its final presentation and maintenance.

The repository is divided into topic-based directories. Each directory contains the material associated with a particular tool or assignment, along with a README describing its contents.

## A Closer Look at the Work

### Beamer: Slide Preparation

The Beamer section demonstrates how LaTeX can be adapted for presentation creation. The included exercise develops a short introductory presentation about LaTeX, using frames to divide the material into individual slides.

It covers the selection of a presentation theme, the construction of a title slide, the arrangement of textual information, and the use of lists and formatting commands. The exercise illustrates how presentation layouts can be defined directly through markup rather than assembled manually.

### Doxygen: Source Code Documentation

This section deals with documenting a small C++ application. The project contains a logging component and a calculation component, providing a practical setting for writing descriptions of classes, functions, parameters, and enumerations.

Doxygen-specific annotations are used to attach structured explanations to the source code. A configuration file is also provided to control the documentation-generation process and its output.

The exercise introduces an approach in which documentation is maintained close to the code it describes and can be generated automatically when required.

### Git and GitHub: Managing Revisions

The Git section introduces the fundamental operations involved in maintaining a version-controlled project.

The exercises use a small project containing a text file and a Python program. Different commands are used to initialize a repository, configure commit information, stage modifications, save revisions, examine differences, and inspect the commit log.

The work also examines how files can be restored or removed and how earlier project states can be accessed. This provides a foundation for understanding how Git records the development history of a project.

### Google Docs: Online Document Preparation

This section focuses on Google Docs as an accessible platform for creating and managing written material.

Its features support the organization of documents through headings, lists, tables, and formatting options. Collaboration tools, comments, suggestions, and version history also make it suitable for documents that require review or contributions from multiple people.

These capabilities are relevant to preparing reports, academic submissions, and other forms of technical communication.

### LaTeX: Structured Technical Writing

The LaTeX section contains exercises that cover a broad range of document-preparation techniques.

The material begins with mathematical notation and gradually introduces more elaborate structures, including aligned equations, matrices, arrays, and tables. Later exercises deal with lists, images, colours, page layouts, and the organization of longer documents.

Taken together, the exercises demonstrate how LaTeX can be used to produce documents with precise formatting and a consistent visual structure.

## Technologies and Applications

The repository brings together several tools, each serving a distinct purpose:

- **LaTeX:** Typesetting mathematical expressions and producing structured documents.
- **Beamer:** Building slide presentations using LaTeX.
- **Doxygen:** Extracting organized documentation from annotated source code.
- **Git:** Recording changes and maintaining a history of project revisions.
- **Python and C++:** Providing sample programs for practical exercises.
- **Google Docs:** Creating, editing, sharing, and reviewing written documents.
- **Linux / WSL:** Supplying a command-line environment for the version-control exercises.

## What Connects These Exercises?

Although the assignments use different applications, they share a common objective: making technical information easier to create, understand, communicate, and maintain.

Document formatting determines how information is presented. Presentations provide a way to communicate selected ideas to an audience. Code documentation explains the structure and behaviour of software, while version control helps preserve the history of the work behind it.

The exercises therefore approach technical communication from several complementary directions rather than treating it as a purely writing-based activity.
